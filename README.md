---

## Run the Project Locally 

Clone the repository and install dependencies :

```bash
git clone git@github.com:babyIsk/portfolio_babylone.git
cd portfolio_babylone
npm install
npm run dev
````

---

## Production Build 

To generate the optimized production version of the project :

```bash
npm run build
````
This command creates a dist/ folder containing the static files ready for deployment.

---

## Deployment 

This project is deployed using GitHub Pages.
After building the project, the production files are published with :

```bash
npm run deploy
````
The live version of the site is available at :
🔗 https://babyIsk.github.io/portfolio_babylone/
